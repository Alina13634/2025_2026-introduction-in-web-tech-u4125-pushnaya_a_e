# Правила участия в проекте

## Работа с ветками

- `main` — стабильная ветка, изменения попадают в неё только через Pull Request
- `develop` — ветка разработки
- Для новой задачи создавайте отдельную ветку от `develop`

## Оформление коммитов

- Один коммит — одно логическое изменение

## Pull Request

1. Создайте ветку и внесите изменения
2. Отправьте ветку на GitHub: `git push origin имя-ветки`
3. Откройте Pull Request с описанием того, что и зачем изменено
4. После проверки и слияния удалите ветку
